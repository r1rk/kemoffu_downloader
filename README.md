# Kemoffu Downloader

`kemono-dl` をGUIから扱うためのマルチスレッド・ダウンローダーです。

大量のURLをまとめて処理したり、保存するコンテンツ・ファイル形式・日付・ファイルサイズなどを細かく指定したり、保存先やファイル名を柔軟にカスタマイズできます。

基本的なダウンロード処理には `kemono-dl` のCLIエンジンを利用し、その上にタスク管理、インメモリ検索、レスポンシブ画像検索、WAF / Turnstile対応、二段階Staging保存、履歴表示、プレビューなどの独自機能を搭載しています。

**日本語** | [English](en.md)

> [!NOTE]
> 本ツールは非常に多くの設定項目を持っています。
>
> GUIでは各項目にマウスカーソルを合わせることで、詳細なツールチップを確認できます。
>
> このREADMEでは主要な機能と、GUI独自の機能・操作について解説しています。
> 各設定項目の細かな仕様については、GUIのツールチップおよび `kemono-dl --help` も参照してください。

## Features

### 🚀 ダウンロード & タスク管理

- **複数URLの一括処理**
  - 1行1URLで複数のURLをまとめて指定
  - ドラッグ＆ドロップによるURL追加にも対応
- **複数タスクの並行処理**
  - 複数のダウンロードタスクを並行して処理
  - 並行プロセス数を設定可能
- **お気に入り一括取得**
  - Kemono / Coomer / Pawchive のお気に入りユーザー・投稿を取得
- **リアルタイム進捗表示**
  - ダウンロード進捗
  - 通信速度
  - ETA
  - タスクごとの状態
  - ログ
- **サスペンド & レジューム**
  - 実行中のプロセスを一時停止・再開
  - タスクの停止にも対応
- **Staging保存**
  - ダウンロードしたデータを一時作業領域へ保存
  - 処理完了後、指定した保存先へまとめて移動

### 📦 保存対象のカスタマイズ

保存するデータを用途に応じて細かく指定できます。

- **添付ファイル**
  - 画像、動画、圧縮ファイルなど
- **本文（HTML）**
  - 投稿本文をHTMLとして保存
  - コメントの保存にも対応
- **インライン画像**
  - 投稿本文に含まれる画像の保存
- **メタデータ（JSON）**
  - 投稿データをJSON形式で保存
- **リンク抽出**
  - 投稿本文内のリンクを抽出
  - ユーザー単位でのリンク抽出
- **ユーザープロファイル**
  - アイコン
  - バナー
  - Fanbox等のファンカード
- **外部動画取得**
  - `yt-dlp` を利用した埋め込み動画の取得

### 🧰 フィルター & ファイル整理

ダウンロード対象を細かく絞り込んだり、保存時のファイル構成をカスタマイズできます。

- **日付フィルター**
  - 公開日を基準とした絞り込み
  - サイトへの追加日を基準とした絞り込み
  - 指定日以前 / 以後 / 当日の指定
- **ユーザー更新日フィルター**
  - クリエイター情報の更新日を基準とした制限
- **ファイルサイズ制限**
  - 最小・最大ファイルサイズを指定
  - 例: `10mb`, `500kb`
- **拡張子フィルター**
  - 許可する拡張子・除外する拡張子を指定
  - GUI上ではチェックボックスによる簡易指定にも対応
- **キーワードフィルター**
  - 投稿タイトルやファイル名を対象とした包含・除外指定
- **階層・ファイル名パターン**
  - 変数を利用して保存フォルダやファイル名を柔軟に設定

例:

```text
{service}/{username} [{user_id}]
````

### ⚙️ ネットワーク & 自動制御

* **エラー処理**

  * `403 Forbidden`
  * `429 Too Many Requests`
  * その他の通信エラーに対する再試行・待機
* **プロキシ**

  * HTTP
  * SOCKS4
  * SOCKS5
  * SOCKS5h
* **プロキシ評価**

  * プロキシごとのエラー状況を記録
  * `proxy_report.txt` へのレポート出力
* **重複防止**

  * 重複チェック
  * ローカルハッシュを利用した検証
* **ダウンロード再開**

  * `.part` ファイルを利用した中断ダウンロードの再開

## GUI独自機能

`kemono-dl` のCLI機能だけではなく、GUI側にもいくつか独自の機能を搭載しています。

### 🌐 WAF / Turnstile アクセス制限への対応

サイト側のセキュリティ機構によって通信がブロックされた場合、GUIから内蔵ブラウザを使用して確認操作を行うことができます。

基本的な流れは以下の通りです。

1. セキュリティ機構によるブロックを検知
2. 確認ダイアログを表示
3. 内蔵ブラウザで対象サイトを開く
4. 必要な確認操作を行う
5. セッション情報を取得
6. 取得したセッションを以降の通信へ適用して再試行

この機能を利用するには `PyQt6-WebEngine` が必要です。

### 🎨 レスポンシブ画像検索（Visual Search）

検索結果を画像付きのカードとして表示する検索モードです。

* ウィンドウ幅に応じてカードの列数を自動調整
* ページ末尾の空き領域に「次のページへ」カードを配置
* 画像取得失敗時の個別リトライ
* ウィンドウサイズ変更に応じたレイアウト変更

### 🔎 インメモリテキスト検索

クリエイター情報をローカルキャッシュし、名前やIDから検索できます。

検索結果には、サイトごとの取得状況や件数などの情報も表示されます。

大量のクリエイター情報を扱う場合でも、毎回ネットワークへ問い合わせることなくローカルキャッシュを利用できます。

### 💾 APPDATAへの設定・データ分離

GUIの設定やキャッシュなど、ユーザー環境に依存するデータをアプリケーション本体から分離して管理します。

Windowsでは、設定やキャッシュ等をOS標準のユーザーデータ領域である

```text
%APPDATA%\Kemoffu
```

に保存します。

これにより、`Program Files` など書き込み権限が制限される場所にアプリケーションを配置した場合でも、アプリケーション本体とは別に設定データを保存できます。

対象となるデータには、以下のようなものがあります。

* `config.json`
* `cookies.txt`
* `creators_cache.json`
* `archive.txt`

### 📁 二段階 Staging 保存

カスタム保存先を指定した場合、ダウンロード中のデータを直接最終保存先へ書き込まず、一時的な作業ディレクトリへ保存します。

基本的な流れは以下の通りです。

```text
インターネット
     │
     ▼
一時作業ディレクトリ
(_temp_staging_batch)
     │
     │ ダウンロード完了
     ▼
指定された保存先
```

これにより、ダウンロード中の細かな書き込みと、最終的な保存先へのデータ移動を分離できます。

### 🔄 Kemono / Pawchive お気に入り移行

内蔵ブラウザを利用して、一方のサイトからお気に入り情報を取得し、もう一方のサイトへ移行する機能を搭載しています。

この機能を利用する場合も `PyQt6-WebEngine` が必要です。

## Requirements & Installation

### 配布版（`.exe`）を利用する場合

GitHub Releases等からビルド済みの実行ファイルを取得して使用できます。

Pythonを別途インストールする必要はありません。

`kemono-dl` を別途指定する必要がある構成の場合は、GUI起動時にファイルの場所を指定できます。

`kemono-dl.py` だけでなく、コンパイル済みの `kemono-dl.exe` も指定できます。

### Python版を利用する場合

Python環境を用意したうえで、必要なパッケージをインストールしてください。

#### 必須パッケージ

```bash
pip install -r requirements.txt
```

`requirements.txt` にはGUI本体および `kemono-dl` の基本動作に必要なパッケージが含まれています。

#### 内蔵ブラウザ機能を利用する場合

WAF / Turnstile確認やお気に入り移行など、内蔵ブラウザを使用する機能には `PyQt6-WebEngine` が必要です。

```bash
pip install PyQt6-WebEngine
```

> `PyQt6-WebEngine` は基本的なダウンロード機能だけを使用する場合は不要です。

#### `yt-dlp` を利用する場合

埋め込み動画の取得機能を使用する場合は、`yt-dlp` も別途用意してください。

```bash
pip install yt-dlp
```

> `yt-dlp` はオプション機能であり、通常のダウンロード処理には必要ありません。

## Basic Usage

### 1. URLを入力する

GUI上部のURL入力欄にURLを入力します。

複数のURLを指定する場合は、1行につき1つのURLを入力してください。

また、URLをGUIへドラッグ＆ドロップして追加することもできます。

クリエイターページのURLを指定した場合は、対象ユーザーの投稿を展開してダウンロード対象として処理できます。

### 2. ダウンロード設定を行う

各タブから、必要に応じて以下のような項目を設定します。

* 保存対象
* 日付
* ファイルサイズ
* 拡張子
* キーワード
* 保存先
* ファイル名
* プロキシ
* 並行処理数
* リトライ設定

各項目の詳細については、GUI上のツールチップを確認してください。

### 3. 保存先を指定する

デフォルトの保存先が設定されています。

必要に応じて保存先を変更できます。

Staging保存を利用する場合も、この保存先が最終的な出力先になります。

### 4. ダウンロードを開始する

設定が完了したら、

```text
▶ ダウンロード開始
```

をクリックします。

実行中は、タスクごとの進捗、通信速度、ETA、ログなどをGUI上で確認できます。

## Advanced Features

### WAF / Turnstile

WAF等によるアクセス制限が発生した場合は、GUIに表示される確認ダイアログから内蔵ブラウザを起動できます。

内蔵ブラウザで必要な確認操作を行った後、セッションを取得して再試行します。

### Visual Search

検索タブから画像検索モードを起動できます。

カード型の検索結果を表示し、ウィンドウサイズに応じてレイアウトが自動的に変更されます。

画像の取得に失敗した場合は、設定されたリトライ回数に応じて個別に再試行します。

### Staging保存

カスタム保存先を使用する場合、ダウンロードしたファイルは一時作業領域に保存され、処理完了後に指定された保存先へ移動されます。

一時作業領域には、主に以下のディレクトリ名が使用されます。

```text
_temp_staging_batch
```

## Important Notes & Limitations

### Cookieについて

Cookieファイルにはログイン状態などの認証情報が含まれる場合があります。

```text
cookies.txt
```

などのCookieファイルを他人へ渡したり、GitHubなどの公開リポジトリへ誤ってアップロードしたりしないよう注意してください。

### ダイレクトメッセージ（DM）について

`--dms` によるDM取得については、対象サイト側の仕様に依存します。

対象サイト側で必要なAPIが提供されていない場合、オプションを指定してもDMを取得できない場合があります。

### サイト側の仕様変更について

本ツールは対象サイトのAPIやページ構造などに依存しています。

対象サイト側の仕様変更によって、既存の機能が正常に動作しなくなる可能性があります。

### 利用規約・著作権について

ダウンロードしたコンテンツの取り扱いについては、対象サイトの利用規約、コンテンツの権利者の権利、および利用地域の法令等を遵守してください。

## Troubleshooting

### `kemono-dl.py` または `kemono-dl.exe` が見つからない

GUI起動時またはダウンロード開始時に `kemono-dl` の場所を指定するダイアログが表示される場合があります。

その場合は、使用する `kemono-dl.py` または `kemono-dl.exe` を指定してください。

一度指定したパスは設定として保存され、次回以降も利用されます。

### Pythonが見つからない

Python版を使用している場合、Pythonが正しくインストールされ、PATHから実行できる状態になっていることを確認してください。

```bash
python --version
```

または環境によっては、

```bash
python3 --version
```

で確認できます。

### 内蔵ブラウザが起動しない

`PyQt6-WebEngine` がインストールされているか確認してください。

```bash
pip install PyQt6-WebEngine
```

### `403 Forbidden` や `429 Too Many Requests` が頻発する

対象サイト側のアクセス制限やレートリミットが原因である可能性があります。

以下の設定を確認してください。

* リクエスト間隔
* レートリミット待機時間
* リトライ回数
* プロキシ設定

WAF等の確認が必要な場合は、GUIのWAF確認機能も利用できます。
