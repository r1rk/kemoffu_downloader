# kemoffu_downloader
Kemono/Coomer/Pawchive Downloader Wrapper

※利用にはL4Cache様の「kemono-dl」が必要です。

`kemono-dl` のCLIをGUIから操作するためのマルチスレッド・ダウンローダーです。

大量のURLをまとめて処理したり、保存するコンテンツ・ファイル形式・日付・ファイルサイズなどを細かく指定したり、保存先やファイル名を柔軟にカスタマイズできます。

基本的なダウンロード処理には `kemono-dl` のエンジン（CLI）を利用し、その上にタスク管理、インメモリ検索、レスポンシブ画像検索、WAF/Turnstile対応、二段階Staging保存、履歴表示、プレビューなどの独自機能を搭載しています。

> **Note**
>
> 本ツールは非常に多くの設定項目を持っています。
>
> GUIでは各項目にマウスカーソルを合わせることで、詳細なツールチップ（説明）を確認できます。
>
> このREADMEでは主要機能とGUI独自の操作について解説しています。

## Features

### 🚀 ダウンロード & タスク管理

- **複数URLの一括処理**  
  1行1URLで複数のURLを指定できます。ドラッグ＆ドロップによるURL追加にも対応しています。
- **複数タスクの並行処理**  
  複数のダウンロードタスクを並行して処理できます。
- **お気に入りの一括取得**  
  Kemono / Coomer / Pawchive のお気に入りユーザー・投稿をまとめて処理できます。
- **進捗のリアルタイム表示**  
  タスクごとの進捗、通信速度、ETAなどをGUI上で確認できます。
- **サスペンド & レジューム**  
  ダウンロード処理全体または個別タスクを一時停止・再開できます。
- **一括移動（Staging保存）**  
  カスタム保存先を使用する場合、一時作業領域へダウンロードした後、処理完了後に指定先へまとめて移動します。

### 📦 保存対象のカスタマイズ

`kemono-dl` の各種オプションをGUIから設定し、保存するデータを細かく指定できます。

- **添付ファイル**  
  投稿に添付された画像・動画・圧縮ファイルなどを保存
- **本文（HTML）**  
  投稿本文をHTMLとして保存
- **コメント**  
  投稿コメントをHTMLへ含めて保存
- **インライン画像**  
  投稿本文に含まれるインライン画像を保存
- **メタデータ（JSON）**  
  投稿のJSONデータを保存
- **リンク抽出**  
  投稿本文からのリンク抽出、およびユーザー単位でのリンク一覧作成
- **ユーザー情報**  
  アイコン、バナー、ファンカード、アナウンスなどの取得
- **外部連携**  
  `yt-dlp` を利用した埋め込み動画の取得

### 🧰 フィルター & ファイル整理

- **日付フィルター**  
  公開日またはサイトへの追加日を基準に、取得対象を絞り込み
- **ユーザー更新日フィルター**  
  クリエイター情報の更新日時を基準に絞り込み
- **ファイルサイズ制限**  
  最小・最大ファイルサイズを指定
- **拡張子フィルター**  
  許可・除外するファイル形式を指定
- **キーワードフィルター**  
  投稿タイトルやファイル名に含まれる文字列による絞り込み
- **階層 & 命名パターン**  
  `{service}`、`{username}`、`{user_id}` などの変数を利用して保存フォルダ・ファイル名をカスタマイズ

### ⚙️ ネットワーク & 自動制御

- **エラー時の自動再試行**  
  ダウンロード失敗やレートリミット発生時の待機・再試行に対応
- **プロキシ制御**  
  HTTP / SOCKS系プロキシを利用可能
- **プロキシ管理**  
  複数のプロキシを使用する場合の状態管理やエラー検出に対応
- **重複防止**  
  ローカルファイルの存在確認やハッシュ比較による重複ダウンロード防止
- **中断したダウンロードの再開**  
  `.part` ファイルを利用したダウンロード再開に対応
- **未掲載ユーザーへの自動リトライ**  
  クリエイター一覧から取得できなかったユーザーについて、強制取得モードへ切り替えて再試行できます。

## ✨ GUI独自機能

### 🌐 WAF / Turnstile アクセス制限への対応

情報取得APIが403などでブロックされ、サイト側のWAF / Turnstileによるアクセス制限が疑われる場合、GUIから内蔵ブラウザを開いて手動確認を行えます。

1. WAF / Turnstileによるアクセス制限が検出されると確認ダイアログが表示されます。
2. 内蔵ブラウザで対象サイトを開きます。
3. 表示されたチャレンジをユーザー自身で完了します。
4. 「セッションを取得して再試行」を実行します。
5. 取得したセッションを利用して、対象の情報取得処理を再試行します。

この機能には `PyQt6-WebEngine` が必要です。

> **Note**
>
> この処理は情報取得APIのWAF対応を目的としたもので、通常のダウンロード処理そのものに毎回ブラウザ確認を要求する仕組みではありません。

### 🎨 レスポンシブ画像検索（Visual Search）

検索タブから利用できるクリエイター画像検索機能です。

- ウィンドウ幅に合わせて検索カードを自動配置
- クリエイター名やIDによる検索
- Kemono / Coomer / Pawchiveごとの検索対象切り替え
- 画像取得失敗時の個別リトライ
- ページ末尾に配置される「次のページへ」カード
- 検索結果からURLを直接ダウンロード対象へ追加

画像取得のリトライ回数もGUIから設定できます。

### 🔎 インメモリ・クリエイター検索

クリエイター情報をローカルキャッシュとして保持し、名前やIDから検索できます。

検索対象となるサービスを切り替えたり、キャッシュを手動で更新したりすることも可能です。

検索結果にはサービスごとの取得状況・件数なども表示されます。

### 🗂️ 履歴表示

ダウンロード履歴をGUI上から確認できます。

履歴タブから、

- 履歴の更新
- `archive.txt` の直接表示

を行えます。

### 🖼️ 保存済みファイルのプレビュー

完了したタスクから保存されたファイルを探し、GUI上から保存内容を確認できます。

### 💾 二段階 Staging 保存

カスタム保存先を使用する場合、ダウンロード処理と最終保存先への書き込みを分離します。

1. ダウンロードしたファイルを一時作業領域へ保存
2. すべてのダウンロード処理が完了
3. 指定された保存先へフォルダ構造を維持したまま移動

一時作業領域には `_temp_staging_batch` が使用されます。

### 🔄 Kemono / Pawchive お気に入り移行

内蔵ブラウザを利用して、一方のサイトに登録されているお気に入り情報を取得し、もう一方のサイトへ移行するための機能を搭載しています。

この機能には `PyQt6-WebEngine` が必要です。

## 必要環境・導入方法

### 1. 配布パッケージ（`.exe`）を使用する場合

リリースからビルド済みのパッケージをダウンロードして使用できます。

Pythonを別途インストールしていない環境でも、配布パッケージからGUIを起動できます。

### 2. Pythonスクリプトとして実行する場合

Python環境を用意したうえで、以下のライブラリをインストールしてください。

```bash
pip install PyQt6 psutil
````

内蔵ブラウザを利用する場合は、追加で以下をインストールしてください。

```bash
pip install PyQt6-WebEngine
```

`PyQt6-WebEngine` を使用する機能には、以下が含まれます。

* WAF / Turnstile確認
* Cookie取得・ログイン関連機能
* お気に入り移行
* その他の内蔵ブラウザ機能

## 基本的な使い方

### 1. URLを入力

画面上部のURL入力欄へ対象URLを入力します。

複数指定する場合は1行につき1URLを入力してください。

検索結果などからURLを追加することもできます。

クリエイターページを指定した場合は、APIからクリエイター情報を取得して投稿を展開し、ダウンロードタスクとして処理できます。

### 2. 各種設定を調整

タブを切り替えながら、必要な項目を設定します。

主な設定項目には、

* 保存対象
* 日付・ファイルサイズ・拡張子などのフィルター
* ファイル名・フォルダ名のパターン
* Cookie
* プロキシ
* リトライ回数
* レートリミット関連設定
* 並行処理数

などがあります。

各設定項目にマウスカーソルを合わせると、ツールチップから詳細な説明を確認できます。

### 3. 保存先を指定

通常の保存先に加えて、カスタム保存先を指定できます。

カスタム保存先を使用した場合は、ダウンロード後にStaging領域から指定先へファイルが移動されます。

### 4. ダウンロード開始

「▶ ダウンロード開始」をクリックすると処理が開始されます。

タスクごとの進捗、通信速度、ログなどをGUI上で確認できます。

## 詳細機能

### WAF / Turnstile

WAF / Turnstileによるアクセス制限が検出された場合は、GUIから内蔵ブラウザを開いて手動確認を行えます。

確認完了後、取得したセッションを利用して情報取得処理を再試行できます。

内蔵ブラウザが利用できない場合は、`PyQt6-WebEngine` がインストールされているか確認してください。

### Visual Search

検索タブの「画像検索モードを起動」から利用できます。

検索結果はウィンドウサイズに応じてカード形式で配置され、検索結果から対象URLを直接ダウンロードリストへ追加できます。

アイコン・バナーの取得に失敗した場合は、設定された回数まで個別に再試行します。

### Staging保存

カスタム保存先を使用すると、ダウンロード中のファイルは一時的に

```text
_temp_staging_batch
```

へ保存されます。

全タスクが完了すると、指定した保存先へフォルダ構造を維持したまま移動されます。

| オプション                                | 説明                            |
| ------------------------------------ | ----------------------------- |
| `--cookies <FILE>`                   | Cookieファイルを指定                 |
| `--inline`                           | 投稿本文中のインライン画像を保存              |
| `--content`                          | 投稿本文をHTMLとして保存                |
| `--comments`                         | 投稿コメントをHTMLとして保存              |
| `--json`                             | 投稿データをJSONとして保存               |
| `--extract-links`                    | 投稿本文からリンクを抽出                  |
| `--extract-all-links`                | ユーザー単位でリンクを抽出                 |
| `--icon`                             | ユーザーのプロフィールアイコンを保存            |
| `--banner`                           | ユーザーのプロフィールバナーを保存             |
| `--fancards`                         | ファンカードを保存                     |
| `--announcements`                    | ユーザーのアナウンスを保存                 |
| `--yt-dlp`                           | `yt-dlp` を利用した埋め込み動画取得        |
| `--date YYYYMMDD`                    | 指定日以降の投稿を取得                   |
| `--datebefore YYYYMMDD`              | 指定日より前の投稿を取得                  |
| `--dateafter YYYYMMDD`               | 指定日より後の投稿を取得                  |
| `--fp-added`                         | 公開日ではなくサイトへの追加日を基準に日付フィルターを適用 |
| `--user-updated-datebefore YYYYMMDD` | ユーザー更新日によるフィルター               |
| `--user-updated-dateafter YYYYMMDD`  | ユーザー更新日によるフィルター               |
| `--min-filesize SIZE`                | 最小ファイルサイズを指定                  |
| `--max-filesize SIZE`                | 最大ファイルサイズを指定                  |
| `--only-filetypes EXT`               | 指定した拡張子のみ取得                   |
| `--skip-filetypes EXT`               | 指定した拡張子を除外                    |
| `--only-postname WORDS`              | 指定した文字列をタイトルに含む投稿のみ取得         |
| `--skip-postname WORDS`              | 指定した文字列をタイトルに含む投稿を除外          |
| `--only-filename WORDS`              | 指定した文字列をファイル名に含むファイルのみ取得      |
| `--skip-filename WORDS`              | 指定した文字列をファイル名に含むファイルを除外       |
| `--dirname-pattern PATTERN`          | 保存フォルダの命名パターンを指定              |
| `--filename-pattern PATTERN`         | 添付ファイルの命名パターンを指定              |
| `--retry COUNT`                      | ダウンロード失敗時の再試行回数               |
| `--ratelimit-sleep SEC`              | レートリミット発生時の待機時間               |
| `--ratelimit-ms MS`                  | リクエスト間隔を指定                    |
| `--proxy PROXY`                      | プロキシを指定                       |
| `--local-hash`                       | 既存ファイルのハッシュを確認                |
| `--dupe-check`                       | 類似ファイル・ハッシュによる重複チェック          |
| `--archive FILE`                     | アーカイブに記録されていない投稿のみ取得          |
| `--force-unlisted`                   | クリエイター一覧を利用せずユーザーAPIを直接取得     |
| `--retry-403 COUNT`                  | 403発生時の再試行回数                  |
| `--archives-password`                | アーカイブファイルのパスワード検索             |
| `--cache-creators`                   | クリエイター一覧をキャッシュ                |
| `--cache-creators-expire SEC`        | クリエイターキャッシュの有効時間              |

完全なオプション一覧は、`kemono-dl` 側で以下を実行してください。

```bash
python kemono-dl.py --help
```

## 注意事項・制限事項

### ダイレクトメッセージ（`--dms`）

現在、対象サイト側の仕様によりDM APIが利用できない場合があります。

その場合、`--dms` を指定してもDM履歴を取得できません。

### Cookie情報の取り扱い

ログイン状態を含むCookieファイルには認証情報が含まれる場合があります。

Cookieファイルを他人へ渡したり、GitHubなどの公開領域へアップロードしたりしないでください。

### 対象サイトについて

対象サイト側の仕様変更、API変更、アクセス制限などによって、本ツールの一部機能が正常に動作しなくなる場合があります。

## トラブルシューティング

### `kemono-dl.py` が見つからない

GUI起動時または初回ダウンロード開始時に `kemono-dl.py` の場所を指定できます。

`kemono-dl.py` を選択する場合は、必要な `src` フォルダも同じ構成で配置してください。

GUIは一度指定したパスを設定として保存し、次回以降も利用します。

### Pythonが見つからない

スクリプト版の `kemono-dl.py` を実行する場合はPythonが必要です。

GUIから `python.exe` の場所を指定してください。

### 内蔵ブラウザが開かない

以下をインストールしてください。

```bash
pip install PyQt6-WebEngine
```

`.exe` 版の場合は、QtWebEngine関連のファイルが配布パッケージに正しく含まれている必要があります。

### 403 Forbidden / 429 Too Many Requests が多発する

以下を確認してください。

* 高度な設定で「リクエスト間隔」を大きくする
* 「レートリミット待機」を大きくする
* 必要に応じてリトライ回数を調整する
* WAF / Turnstileの確認ダイアログが表示された場合は、内蔵ブラウザで手動確認を行う
* 必要に応じてプロキシを設定する

## データ・設定ファイルについて

GUIが使用する設定や履歴などのデータは、ユーザー用データ領域に保存されます。

主なデータには以下があります。

| ファイル / ディレクトリ |             用途            |
| --------------------- | ----------------------------|
| `config.json`         | GUI設定                     |
| `cookies.txt`         | Cookie情報                  |
| `creators_cache.json` | クリエイター検索用キャッシュ  |
| `archive.txt`         | ダウンロード履歴             |
| `_temp_staging_batch` | Staging保存時の一時作業領域  |

これらのファイルにはCookieなどの機密情報が含まれる場合があるため、取り扱いには注意してください。
